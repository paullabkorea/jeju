# 만조 滿潮 — 제주 탑동 카페 랜딩페이지

제주더큰내일센터 1층에 들어설 카페의 랜딩페이지 시안입니다.
빌드 도구 없이 파일 세 개로 동작합니다.

```
index.html   구조
styles.css   디자인 (현무암 · 감귤 · 제주바다 팔레트)
script.js    메뉴 / 지도 / 아이디어 카드 / 일몰·만조 시각
```

## 보는 방법

`index.html`을 브라우저로 그냥 열어도 되고, 로컬 서버로 띄워도 됩니다.

```bash
python -m http.server 5599
```

## 요구사항 대응

| 요구사항 | 구현 |
| --- | --- |
| 1. 위치: 제주더큰내일센터 1층 | 히어로·오시는 길·푸터에 표기, 주소 복사 버튼 |
| 2. 공항에서 오는 길을 Leaflet 지도로 | `#visit` 섹션. 공항·카페 마커, 예상 경로 점선, 용두암·탑동광장 경유지, 택시/버스/렌터카 탭 |
| 3. 독특한 제주 메뉴 | 16종. 감귤 말차 티는 **‘귤빛 말차’**로. 분류 필터 제공 |
| 4. 성공을 위한 상상 | `#lab` 섹션에 여덟 가지 아이디어. 카드를 골라 번호 복사 가능 |

## 고칠 때 보면 되는 곳

- **좌표** — `script.js` 상단 `CAFE`. 지금은 탑동 기준 **근사값**이라 실측 좌표를 넣으면 지도·경로가 그대로 맞춰집니다. `AIRPORT`, `ROUTE`(경로 꺾이는 점들)도 같은 자리에 있습니다.
- **메뉴** — `script.js`의 `MENU` 배열. `cat`은 `signature | coffee | tea | dessert`, `best: true`면 BEST 뱃지가 붙습니다.
- **아이디어** — `script.js`의 `IDEAS` 배열.
- **색·서체** — `styles.css` 맨 위 `:root` 변수.

## 정확도 메모

- **경로 점선**은 실제 내비게이션 경로가 아니라 공항 → 용담 해안도로 → 용두암 → 서부두 → 탑동을 따라 손으로 찍은 예상선입니다. 실제 경로 API를 붙이려면 카카오/티맵 길찾기 API가 필요합니다.
- **버스 노선 번호**는 계절·시간대에 따라 자주 바뀌어 일부러 적지 않고 제주버스정보시스템 링크로 대체했습니다.
- **일몰 시각**은 NOAA 근사식으로 계산합니다(오차 1~2분).
- **만조 시각**은 달의 위상으로 낸 **추정값**이라 `≈`를 붙였습니다. 실제 물때는 국립해양조사원 자료를 받아야 정확합니다.
- 전화번호·이메일·영업시간은 자리를 채워 둔 예시 값입니다.
